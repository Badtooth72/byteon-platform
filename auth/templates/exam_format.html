For a word bank, put [[1]], [[2]], etc. where each blank goes.

Case and repeated whitespace are ignored. Values are otherwise matched exactly.

Words can be reused. Each blank receives an equal share of the marks.

All selected options must match for full marks. No marks for ticking extra answers.

Example: Router | Connects different networks. Right-hand items are rearranged in the question. Equal marks per correct pair.

Addition retains any extra carry bit. Shifts use the fixed width and discard bits outside it. Working can be reviewed by a teacher.

Prose, essays and code require teacher marking. Algorithms use a lenient syntax policy; Python uses a formal policy with minor leeway. Student code is not executed.
