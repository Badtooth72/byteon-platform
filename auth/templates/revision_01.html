1.1 SYSTEMS ARCHITECTURE

The CPU and its job

The CPU processes instructions. In the fetch–execute cycle, an instruction is fetched from memory, decoded by the control unit and executed. The cycle repeats while the program runs. A Von Neumann system stores instructions and data in main memory.

Know the parts

  • Control unit (CU): coordinates operations and interprets instructions.
  • Arithmetic logic unit (ALU): performs arithmetic and logical operations.
  • Registers: tiny, very fast stores inside the CPU. The program counter holds the address of the next instruction; MAR holds a memory address; MDR holds data being transferred; the accumulator holds a result.
  • Cache: fast storage close to the CPU for frequently needed instructions and data, reducing slower RAM accesses.

For the exam, explain what each component stores or does. You do not need to memorise every transfer between registers during each stage of the cycle.

Performance and embedded systems

A higher clock speed permits more cycles each second; more cores can execute independent work in parallel; a larger cache may reduce trips to RAM. None guarantees a fixed improvement: software, workload, heat and other bottlenecks matter. An embedded system is a computer built into a larger device for a specific purpose, such as a washing-machine controller.

Exam-style explanation“A larger cache may improve performance because the CPU can access frequently used data faster than retrieving it from RAM.” Name the factor, describe its effect and connect it to the scenario.

1.2 MEMORY AND STORAGE

Where data lives

RAM holds programs and data currently in use and loses its contents when power is removed. ROM retains essential startup instructions. Virtual memory moves data between RAM and secondary storage when RAM is full; it provides capacity but is slower than RAM. Secondary storage keeps files when power is off.

Choose storage for a scenario

Compare magnetic, optical and solid-state devices using capacity, speed, portability, durability, reliability and cost. For example, an SSD has no moving parts and is usually fast, but cost per gigabyte can be higher than for a hard disk. An optical disc may suit physical distribution but has limited capacity and speed.

Units and number bases

A nibble is 4 bits; a byte is 8 bits. OCR accepts either 1,000 or 1,024 when converting larger units if your working is clear. For an eight-bit unsigned binary value, the place values are 128 64 32 16 8 4 2 1. Hexadecimal groups four bits into one digit; A to F represent decimal 10 to 15. An eight-bit value ranges from 0 to 255. Adding beyond that range causes overflow if the result must stay eight bits. A left shift moves bits towards higher place values; a right shift moves them towards lower ones, with zeros filled into the vacant positions for the unsigned values used here.

Worked conversion10110110₂ = 128 + 32 + 16 + 4 + 2 = 182₁₀. Split into 1011 0110 to get B6₁₆. Always show the place-value working when asked to explain.

Characters, images, sound and compression

Character sets map binary codes to characters. A larger number of bits permits more possible codes; Unicode covers a broader range of writing systems than ASCII. You are not expected to memorise character code numbers. A bitmap consists of pixels: width × height × colour depth estimates its uncompressed bit count, ignoring metadata. A digital sound records samples: sample rate × bit depth × duration estimates bits for mono sound, ignoring metadata. Higher resolution, colour depth, sample rate or bit depth generally increases data size and may improve fidelity.

Lossless compression reconstructs the original exactly and suits program files. Lossy compression discards some information and may suit photos or audio where smaller files matter more than perfect reconstruction.

1.3 NETWORKS, CONNECTIONS AND PROTOCOLS

How computers connect

A LAN covers a small local area under one organisation; a WAN spans a larger geographic area and may link LANs. In a client-server network, clients request services from a server; in peer-to-peer networks, devices can share resources directly. Client-server centralises accounts and files but needs server management. Network performance depends on bandwidth, number of connected devices and the work being done.

Hardware, topologies and the Internet

  • A NIC connects a device to the network. A switch forwards traffic within a LAN; a router connects networks; a wireless access point connects Wi-Fi devices to a wired network.
  • In a star topology, devices connect to a central device. It is straightforward to manage, but the central point is critical. A mesh provides multiple paths and resilience but needs more connections.
  • The Internet is a network of networks. A web client requests pages from a web server. DNS helps turn a domain name in a URL into an IP address. Cloud services provide remote storage, software or processing.

Connections and protocols

Ethernet is usually stable and fast where cabling is practical. Wi-Fi allows mobility but can face interference; Bluetooth is useful for short-range connections. An IP address identifies a device on a network, while a MAC address identifies a network interface. A protocol is a set of communication rules; standards help equipment from different makers work together. Layers divide networking work into manageable parts; the exam does not require names of individual TCP/IP layers.

1.4 NETWORK SECURITY

Threats and defences

Threats include malware (malicious software), phishing and other social engineering, brute-force password attacks, denial of service, interception or theft of data, and SQL injection. Name the mechanism in an answer: “phishing tricks a user into giving credentials” explains more than simply saying “hacking”.

Choose a suitable defence

  • Strong authentication and access levels limit who can sign in and what they may change. Password policies and multi-factor authentication reduce some account risks.
  • Encryption protects data in transit or at rest from being read without a key. It does not itself stop deletion or prevent someone using a stolen signed-in session.
  • Firewalls filter traffic against rules; anti-malware scans for malicious software; updates fix known weaknesses.
  • Penetration testing deliberately checks for vulnerabilities with permission. Physical security protects equipment from theft or unauthorised access.

1.5 SYSTEMS SOFTWARE

Operating systems and utilities

An operating system provides the interface between user, applications and hardware. It manages memory allocation, processor time, peripherals, files and user accounts. Scheduling lets several programs make progress. File management covers naming, saving, moving and organising files; user management covers accounts and rights. You need the purpose of these functions, not low-level paging or segmentation.

Utility software performs additional housekeeping. Encryption software makes data unreadable without the key. Compression reduces file size. Defragmentation reorganises fragmented data on a magnetic hard disk; it is not the normal way to speed up an SSD.

Explain a benefit, not just a name“The OS allocates RAM to each running program so they can operate without using the same memory in conflicting ways.”

1.6 IMPACTS AND LEGISLATION

Think beyond the device

Digital technology can affect privacy, fairness, employment, culture and the environment. A good extended response discusses more than one stakeholder, weighs benefits against drawbacks and reaches a reasoned conclusion for the scenario. For example, remote work may reduce commuting but increase home and data-centre energy use. Automated decisions may save time but could reproduce bias in training data. The digital divide means people with limited connectivity, money or skills may be excluded.

Legislation and licences

  • Data Protection Act 2018: concerns lawful handling of personal data.
  • Computer Misuse Act 1990: addresses unauthorised access and related computer misuse.
  • Copyright, Designs and Patents Act 1988: protects creative works, including software, against unauthorised copying.
  • Software licences: set the terms for use. Open-source licences provide source access and permitted modification under conditions; proprietary software commonly keeps source closed and restricts changes.
