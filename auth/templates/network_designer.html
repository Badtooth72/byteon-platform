    Network reference desk

    A switch connects devices within a LAN. A router forwards data between networks. A wireless access point joins wireless devices to a network. Each device needs a NIC. Wired and wireless connections have different reliability, mobility and interference trade-offs.

    In a star, links meet at a central device. Mesh networks provide multiple paths, at greater cost and complexity. Client-server networks centralise services; peer-to-peer computers share resources directly.

    The Internet connects networks worldwide. DNS resolves names to IP addresses; hosting makes website content available on web servers. Cloud services provide remote storage, software and processing.

    TCP/IP supports Internet communication: TCP manages reliable delivery and IP supports addressing and routing. HTTP transfers web content; HTTPS encrypts web traffic. FTP transfers files. SMTP sends mail; POP retrieves it; IMAP synchronises server-held mail.

    IPv4 uses four decimal octets; IPv6 uses hexadecimal groups. MAC addresses identify network interfaces on a local network. Standards enable compatibility; protocols set communication rules; layers separate responsibilities.

    Security threats include malware, phishing, brute force, denial of service, interception and SQL injection. Defences include anti-malware, firewalls, access levels, strong passwords, encryption, physical security and authorised penetration testing. No single defence prevents every attack.
