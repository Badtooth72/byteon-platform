# Arcade art sources

The images in this folder are excerpts from Kenney's CC0 game asset packs.
The original author and licence text are in the adjacent LICENSE files.

- `shmup-ships.png`: Pixel Shmup, https://kenney.nl/assets/pixel-shmup
- `platform-characters.png` and `platform-tiles.png`: Pixel Platformer, https://kenney.nl/assets/pixel-platformer
- `ui-space-panel.png`: Pixel UI Pack, https://kenney.nl/assets/pixel-ui-pack

The selected sprites were retrieved from the public pack mirror at
https://github.com/Tiddybub/2d-assets because the school's web proxy blocked
Kenney's ZIP download endpoint. The source links and pack licence files were
checked against Kenney's published CC0 asset pages.
